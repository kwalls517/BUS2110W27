Managing systems

Building the system is not the end

After development and testing comes implementation: switching the organization to the new system, training people, and then keeping the system healthy during maintenance. How you switch matters. There are four common ways.

Direct

Turn off the old system and switch to the new one on a set date. Fast, but risky if the new system fails.

Parallel

Run the old and new systems side by side for a while. Safe, but double the work.

Phased

Switch one part at a time. Lower risk, but it takes longer.

Pilot

Try the new system with one small group first. Problems show up early and stay small.

Messy data

Garbage in, garbage out

The new system is live, but the data moved into it is a mess. Raw data is almost always incomplete, incorrect, or inconsistent. Data cleaning is the process of finding the incomplete, incorrect, inaccurate, or irrelevant parts of the data and replacing, fixing, or deleting them.

Time-consuming

Cleaning is often the longest and least enjoyable part of analytics.

Essential

It is also the most important step. Bad data produces bad results.

Everywhere

Any time data moves into a new system, hidden problems tend to surface.
Messy data

Five kinds of dirty data

Missing values

Gaps from collection errors. A row with an item but no price.

Duplicates

Rows that appear twice. They inflate totals.

Inconsistent formats

Mixed dates or capitalization, such as East, east, and EAST.

Outliers

Extreme values that skew results, like a $1,500,000 burger.

Irrelevant data

Columns or rows that do not help answer the question.
Each kind damages the analysis differently. Missing values make revenue wrong, duplicates inflate it, formats break grouping, outliers distort averages, and irrelevant data adds noise.

Excel: Chapter 4

A dataset is organized in rows and columns

In a dataset, each row is one record, such as an order, and each column is one field, such as price. Excel can turn a dataset into a table, which adds tools that make data easier to manage.

Filter arrows

Show only the rows you need.

Banded rows

Alternating colors keep rows readable.

Auto-expanding

New rows join the table and its formulas.

Structured references

Formulas use column names, like [@Qty]*[@Price].
To make a table, select any cell in the data and press Ctrl+T. Check that the headers box is ticked.
